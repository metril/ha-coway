Setup (Wi-Fi)
  1. Hold the purifier's Wi-Fi button until the Wi-Fi LED blinks (pairing mode).
  2. Join the open Wi-Fi network Airmega_400s on a laptop.
  3. Download the single-file CLI (stdlib only): curl -O https://raw.githubusercontent.com/metril/ha-coway/main/coway_bridge/app/coway_bridge/setup_cli.py
  4. Enter the serial number from the unit's label (filled in automatically once a unit has connected) and your SSID below, then run the generated command on that laptop. The CLI prompts for the Wi-Fi password.
  5. Rejoin your normal Wi-Fi; the purifier should appear here within ~1 min.

      
      
The command has no password: the CLI asks for it on the laptop, so it never appears here or in shell history.
