Wi-Fi setup

Connect a purifier to your Wi-Fi without the IoCare app.
  1. 1
    Put the purifier in Wi-Fi setup mode
    See the purifier's manual or the IoCare app instructions.
  2. 2
    Join its setup network from a laptop
    Connect to the open network the purifier broadcasts (usually named Airmega…).
  3. 3
    Download the setup tool
    Python 3, no dependencies.
    curl -O https://raw.githubusercontent.com/metril/ha-coway/main/coway_bridge/app/coway_bridge/setup_cli.py
  4. 4
    Run it
    Serial is prefilled from the connected purifier; enter your Wi-Fi name.
  5. 5
    Reconnect your laptop to normal Wi-Fi
    The purifier should appear on the Device tab within about a minute.
The tool asks for the Wi-Fi password itself — it is never entered here.
Purifier not showing up?
  1. pfSense → Firewall → NAT → Port Forward on the IoT interface: source = purifier IP, destination = any (not a fixed cloud IP), TCP 9090 → Home Assistant IP:9090. DNS overrides do not work: the purifier also asks 8.8.8.8.
  2. Allow IoT → Home Assistant:9090 in the firewall rules.
  3. Make the purifier reconnect: kill its 9090 state in Diagnostics → States, or deauthenticate it from the Wi-Fi AP. Never unplug it — it loses its Wi-Fi credentials.
  4. Check the app log for purifier connect / TLS handshake warnings.
